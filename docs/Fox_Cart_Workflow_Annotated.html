API
Preflight validates the orders and takes the cart lock
inventory_api · POST /vendors/{vendorId}/cart/preflight (user sign-in)
Creates the session (2 hours), takes the vendor's cart lock, and returns session_id, callback_token, vendor_key, expires_in_seconds and the items. A cart in use or orders in another open session are refused with a message the panel shows. If the user cancels while preflight runs, the provider releases the session as soon as preflight returns.
PWA
start_fill carries the preflight payload to the extension
ExtensionCartProvider.tsx · startCartFill()
The vendor key comes from preflight. If the extension refuses, or does not answer within 10 seconds (missing or too old), the provider releases the session through the API and shows why.
ExtensionCartProvider.tsx · start_fill

      order_id: item.order_id,
      part_name: item.part_name,
      code: item.vendor_code,
      quantity: item.quantity,

});
02
Extension accepts the session
background.js · handleStartFill()core/session-store.js
EXT
Validate, store, reply at once
src/background.js · handleStartFill()
The sender must be an approved PWA origin; the API address comes from api-origins.js for that origin, never from the message. The payload is validated, and an unknown vendor key is refused (unsupported_vendor). One session per browser: a different active session is refused (session_in_progress); the same session again re-attaches the sending PWA tab. The session is stored in chrome.storage.session, the login and expiry alarms are set, and the reply is accepted before any vendor work starts.

content.isolated.js · checkIdentity()
async function checkIdentity() {
  const kd = await requestKdValues();
  const rightCompany = Number(kd.companyId) === Number(COMPANY_ID);

  if (kd.isLoggedIn && rightCompany) {
    removeElement(LOGIN_BANNER_ID);
    return { status: 'logged_in' };
  }

  const status = kd.isLoggedIn ? 'wrong_account' : 'login_required';
  showLoginBanner(status === 'wrong_account');
  return { status };
}

04
Fill the Fox cart
content.isolated.js · fillCart()
FOX
Read the cart, stop if not empty, then bulk add
src/vendors/fox/content.isolated.js · fillCart()
The cart is read with viewCart. Any line → cart_not_empty: nothing is added or removed, the lines are shown, and the background releases the lock. Empty → one bulk add. If Fox refuses the add because its login expired after the page loaded, the result is login_required: the background returns to the login wait and reloads the tab. A failed add still reads the cart and reconciles what is there.
content.isolated.js · fillCart() (excerpt)
const before = await readCart();
if (before.cart_lines.length > 0) {
  return { status: 'cart_not_empty', ...before, vendor_errors: [] };
}
05
Reconcile after the fill
background.js · reconcileAndStore()POST /vendors/cart/reconcile
API
The API compares the cart with the session's orders
inventory_api · POST /vendors/cart/reconcile (callback token, trigger fill)
Orders whose code is in the cart become cart_filled (quantity follows the cart); missing ones stay pending; cart lines not in the order are recorded as extra lines.

content.isolated.js · tab observer
tabObserver = new MutationObserver(() => {
  const index = activeTabIndex();
  if (index === lastTabIndex) return;

  const previous = lastTabIndex;
  lastTabIndex = index;

  if (index === 0) void onCartTab();
  else if ((index === 1 || index === 2) && previous !== 1 && previous !== 2) void onCheckoutEntered();
});

background.js · submit
if (message.action === 'submit') {
  const result = await api.markOrdered(session);
  if (!result.ok) return failAction(session, result);

  await endSession(session.session_id, 'completed', {
    orders_marked: result.data?.orders_marked ?? 0,
    not_ordered: result.data?.not_ordered ?? [],
  });
  return { ok: true };
}

Release cart
Fox overlay, or the PWA panel
Overlay: POST /vendors/cart/release. PWA panel: POST /vendors/cart/abandon-session/{id}, then end_session to the extension. Release does not change the Fox cart; its lines stay until removed on Fox.
